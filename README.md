# Critz Kingdom Conquest

Game design vault and playable early battlefield prototype.

## Play locally

```sh
python3 -m http.server 8765 --directory prototype
```

Open http://localhost:8765 in your browser. See [prototype/README.md](prototype/README.md) for controls, features, and current limitations. This first prototype uses a local canvas simulation; it is not yet networked multiplayer.

Design notes remain in `ideas/`.

For Windows and Unreal testing, see [PC_HANDOFF.md](PC_HANDOFF.md).
